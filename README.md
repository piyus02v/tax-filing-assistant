# 🇮🇳 Tax Filing Assistant - Production RAG System

AI-Powered Tax Filing Assistant for Indian SMBs using RAG (Retrieval-Augmented Generation)

## 🚀 Quick Start

```bash
git clone https://github.com/yourusername/tax-filing-assistant.git
cd tax-filing-assistant
cp .env.example .env
# Add your OpenAI API key to .env
docker-compose up -d
```

## ✨ Features

- ✅ Field-Level AI Suggestions for tax forms
- ✅ Official Document Citations (ITR/GST)
- ✅ Context-Aware Recommendations
- ✅ Production-Ready Architecture

## 🛠️ Tech Stack

- Backend: Node.js, TypeScript, Express
- Frontend: React 18, Tailwind CSS
- Databases: PostgreSQL, Qdrant Vector DB
- AI: OpenAI (Ada-002 + GPT-4)
